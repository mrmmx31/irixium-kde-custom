# Irixium 4.1 (Aurorae)

Cópia completa do tema local `aurorae/themes/irixium`, versão 4.1 de
Mark Whittaker (Phob1an), publicado em
[KDE Store](https://store.kde.org/p/2142963).
O pacote independente usa o ID `irixium_modern_41` e preserva os arquivos
originais em `package/assets/` e `package/upstream/`.

O layout tem menu nativo do KWin, minimizar e maximizar/restaurar. O botão
fechar não é criado. Padding, SVGs, restauração e métricas da versão 4.1
permanecem próprios desta opção.

Os metadados originais declaram GPL-2.0+, enquanto o arquivo LICENSE original
contém GPLv3. Ambos estão preservados sem alterações: o empacotamento registra
essa divergência em ORIGEM.json, sem substituir a declaração do autor.
O código de adaptação declara GPL-3.0-or-later; o pacote declara GPL-3.0.

Instalação e testes estão descritos em [decorations/README.md](../README.md).
