# Irixium 1.3 (Aurorae)

Cópia completa do tema local `aurorae/themes/Irixium`, versão 1.3 de Phob1an,
publicado em [KDE Store](https://store.kde.org/p/1457768).
O pacote independente usa o ID `irixium_modern_13` e preserva os arquivos
originais em `package/assets/` e `package/upstream/`.

O layout tem menu nativo do KWin, minimizar e maximizar/restaurar. O botão
fechar não é criado. A arte, as métricas e os estados pertencem à versão 1.3;
o pacote `irixium_modern` existente continua separado.

Os metadados originais declaram GPL3, e o arquivo LICENSE original contém
GPLv3. Ambos estão preservados. O código de adaptação declara GPL-3.0-or-later.

Instalação e testes estão descritos em [decorations/README.md](../README.md).
