# IrixClassic 0.7.1 — instalar o tema estável

Extraia `IrixClassic-0.7.1-kvantum.zip`. No Kvantum Manager, instale a pasta
**IrixClassic**, selecione-a e reabra os aplicativos. No KDE, Application Style:
**kvantum**. O plugin deve ser fornecido pela distribuição. Sem sudo.

Antes de substituir uma cópia personalizada, guarde a pasta do tema ou use o
instalador recuperável do pacote `IrixClassic-0.7.1-codigo.zip`. Quem já usa a
candidata 0.7.1-rc1 terá a mesma aparência; a atualização identifica a versão
estável e não exige reaplicar correções do KDE ou a decoração.

Este ZIP não executa scripts nem instala fontes, ícones, GTK, decoração KWin,
estilo Plasma, ou o reparo compartilhado de pressão das setas Qt Quick.
Leia `README.md` para escopo, créditos e limites. `MANIFEST.json` e `PACOTE.json`
permitem verificar o conteúdo; `SHA256SUMS` acompanha a release. Não são assinaturas.

Versão aceita no ambiente de referência Debian 13 / KDE Wayland / Qt 6.8.2 /
Kvantum 1.1.4. Isso não é certificação de todos os aplicativos e distribuições.
