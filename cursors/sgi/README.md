# SGI cursor

This directory preserves the `sgi` cursor theme used by the local KDE
configuration. It is sourced from the `cursor/sgi` directory of
[`jujum4n/sgi-enhanced`](https://github.com/jujum4n/sgi-enhanced).

The payload was compared with `~/.icons/sgi`. Eight upstream absolute links
that pointed to another user's home directory were normalized to equivalent
relative links so the theme remains portable.
