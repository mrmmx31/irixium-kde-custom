# IrixClassic Plasma Style

This is the Irixium Plasma Style copied as the starting point for the
independent IRIX Classic theme. It is intentionally named **IrixClassic** so
future Classic visual changes do not overwrite the modern style.

The current artwork is still the upstream Irixium artwork; no Classic-specific
visual changes have been made yet. The package metadata identifies **Phob1an**
as the source author and declares GPL3. `LICENSE` is retained from the source
package.

See `ORIGEM.json` for provenance and the intentional separation.
