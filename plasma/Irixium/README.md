# Irixium Plasma Style

This is the installed Irixium Plasma Style from the KDE Store / OpenDesktop
package [1457753](https://www.pling.com/p/1457753/).

The package metadata identifies **Phob1an** as author and declares GPL3.
`LICENSE` is retained from the installed package. No local visual changes have
been made.

See `ORIGEM.json` for the provenance record.

The Wi-Fi/Bluetooth switch resource (`widgets/switch.svg`) is restored from
the author’s Irixium 6.2. Without it, Plasma falls back to the default KDE switch.
This resource is GPL-2.0-or-later; see `ORIGEM.json` for its provenance.
