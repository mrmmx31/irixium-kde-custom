# Changelog

## 0.1.0 — 2026-10-06

Primeira versão instalável de IrixClassic-SGI: 110 composições vetoriais distintas, 126 ícones-base, 292 nomes, oito tamanhos PNG e SVGs editáveis. Inclui gerador, instalador independente, auditor, criador opcional de Irixium-Fixed, patch mínimo de metadados do Irixium, documentação de escopo/proveniência e testes de regressão. Sem alterações remotas no GitHub e sem validação numa sessão real de KDE.
