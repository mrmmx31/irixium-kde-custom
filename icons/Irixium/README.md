# Irixium icons

This is the installed Irixium icon theme, preserved from the KDE Store /
OpenDesktop package [2142965](https://www.pling.com/p/2142965/).

The snapshot identifies itself as **Irixium** and describes itself as
“Remixed NsCDE”. Its installed files do not include a license notice, so this
repository does not add or guess one. The original metadata is preserved;
redistribution remains subject to confirmation of the package's license.
