# IrixClassic Files 0.1.0-alpha1

Primeira versão **experimental**, baseada no Dolphin 25.04.3 com os patches
Debian 4:25.04.3-1+deb13u1. Não é uma versão oficial KDE/SGI e não substitui o
Dolphin instalado.

Interface inspirada no Icon View: Pathfinder, ancestrais e histórico; barra
vertical e zoom; Shelf contextual de referências; Content Viewer de texto e
imagens locais. As ações nativas de arquivos, abas e split view são reaproveitadas.

Dados e bibliotecas próprios, instalação somente no usuário. Preview remoto,
PDF, mídia, ícones SGI originais, gestos completos de thumbwheel e sons específicos
não fazem parte desta alpha. O visualizador é limitado e cancelável, não sandbox.

Use inicialmente dados de teste. A construção exige testes nativos aprovados;
a aceitação gráfica Wayland e a regressão de todos os fluxos ainda são trabalho
de evolução. Reporte versão, passos e resultados esperados/obtidos sem dados
pessoais ou credenciais. Créditos upstream e licenças estão na fonte correspondente.

Distribuição: binário Linux da arquitetura indicada, fonte correspondente e
SHA256SUMS. Dependências Qt/KDE vêm do Debian 13. Pacotes não assinados.
